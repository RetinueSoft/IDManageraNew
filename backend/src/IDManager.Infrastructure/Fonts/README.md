# Fonts

Noto Sans and Noto Sans Tamil (Regular and Bold), from https://github.com/notofonts,
licensed under the SIL Open Font License 1.1 (https://openfontlicense.org).

They are embedded in the assembly and used by `PdfGenerationService` so that cards
print Latin text and Tamil text (shaped with HarfBuzz) the same on any server.
